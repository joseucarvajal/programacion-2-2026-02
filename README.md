Las variables tienen tipos (eg: str: string, int: entero, float: un número flotante o con decimal). Ejemplo:
nombre_del_perro = "Tutu"
edad_del_perro = 23 "23": no debería ser con comillas
como pregunto si mi perro tiene menos de 5 años: if(edad_del_perro < 5)
